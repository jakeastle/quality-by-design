# Quality by Design

Hands-on Playwright and modern quality engineering focused on product risk, release confidence, and scalable automation.

## What This Demonstrates

- Playwright automation with TypeScript
- Cross-browser test execution
- Reliable locator strategy
- Failure diagnosis and test correction
- CI-ready project structure
- Practical regression coverage concepts

## Tech Stack

- Playwright
- TypeScript
- Node.js
- GitHub Actions

## Current Coverage

- TodoMVC end-to-end workflow
- Add todo items
- Complete a specific todo item
- Validate remaining active item count

## Quality Philosophy

Quality should be designed into delivery, not inspected in at the end. This project is a hands-on space for building modern automation habits that support release confidence, product risk assessment, and scalable testing.
